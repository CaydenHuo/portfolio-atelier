# Portfolio Atelier

一套用 AI 把项目整理成高级产品作品集的工作流。

Portfolio Atelier 不是 PPT 模板，也不是单页美化 prompt。  
它更像一个作品集工坊：先找到项目的北极星，再搭建叙事脊梁，压缩页面文字，建立视觉密码，最后用面试官视角做压力测试。

这套 workflow 最初用于「地瓜灵感」微信小程序作品集制作。  
它适合正在准备产品经理、AI 产品经理、UX、创作者工具方向作品集的人。

## What it does

Turn a project from:

> 我做了很多功能

into:

> 我看见了一个真实问题，并把它做成了一个有判断的产品。

## Core idea

A portfolio is not a feature list.  
It is a sequence of decisions.

作品集不是功能清单，而是一串清晰的产品判断。

## Skills

### 01 North Star Skill
找到项目的产品北极星，把“做了什么功能”改成“解决了什么问题”。

### 02 Narrative Spine Skill
搭建作品集叙事脊梁，让页面从背景、洞察、方案、创新、技术、指标自然推进。

### 03 Sharp Copy Skill
把说明书式文字压缩成标题、判断句和英文小字。

### 04 Visual Code Skill
先建立视觉密码，再生成页面，保证整套 PPT 审美统一。

### 05 Page Craft Skill
基于视觉母版分批生成页面，避免一次生成失控，也避免单页风格漂移。

### 06 Depth Signal Skill
补强 AI 产品深度：上下文、记忆、模型、数据、反馈闭环和指标。

### 07 Pressure Test Skill
用面试官视角高压追问，提前发现作品集里的薄弱点。

### 08 Last Light Skill
最后一轮审美、逻辑、表达和面试风险校准。

## How to use

建议按这个顺序使用：

1. North Star Skill
2. Narrative Spine Skill
3. Sharp Copy Skill
4. Visual Code Skill
5. Page Craft Skill
6. Depth Signal Skill
7. Pressure Test Skill
8. Last Light Skill

## Principle

不要让 AI 直接“美化 PPT”。  
先让 AI 帮你重构叙事，再建立视觉母版，最后分批生成页面。

生图负责氛围，PPT 负责文字。  
每页只保留一个核心判断。
