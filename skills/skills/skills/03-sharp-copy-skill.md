# 03 Sharp Copy Skill

## 用途

把说明书式文字压缩成作品集表达。

它帮助你把冗余、白话、功能说明式文案，改成标题、判断句和英文小字。

## Prompt

请你帮我优化作品集 PPT 的页面文案。

要求：
1. 删掉冗余解释
2. 把功能描述改成产品判断
3. 把白话表达改成克制、有质感的表达
4. 每页只保留一个核心观点
5. 不要写成说明书
6. 不要使用“赋能、闭环、抓手、生态”等套话
7. 适合放在高级产品作品集里

请按下面格式输出：

原文：


优化后：
- 主标题：
- 核心判断句：
- 英文小字：
- 可选补充标签：

请给我 3 个版本：
1. 克制专业版
2. 更有审美版
3. 更适合面试表达版
