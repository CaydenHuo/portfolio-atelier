# 05 Page Craft Skill

## 用途

基于已经确认的视觉母版，分批生成作品集页面。

## 推荐方式

先生成 Styleboard，再分批生成：

- Batch 1：Page 01-03
- Batch 2：Page 04-07
- Batch 3：Page 08-10

## Prompt

请严格沿用已确认的 Styleboard，生成以下页面。

要求：
1. 保持统一背景、字体、logo、页眉页脚、材质和强调色规则
2. 不要每页重新发明风格
3. 保持 16:9 横版
4. 中文文字必须清晰，不要乱码
5. 每页只保留一个主标题、一句核心判断、少量英文小字
6. 视觉要服务叙事，不要只做漂亮海报
7. 如果无法保证中文清晰，请优先生成无文字背景和版式占位，我会后期手动加字
