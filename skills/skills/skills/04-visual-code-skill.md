# 04 Visual Code Skill

## 用途

建立作品集的视觉密码。

它解决的问题不是“让 PPT 变好看”，而是防止 AI 生图时每一页都重新发明风格，导致整套作品集不统一。

## 核心原则

先定视觉密码，再生成页面。

不要直接让 AI 画 10 页。  
先让 AI 明确：

- 这套作品集像什么
- 不像什么
- 背景怎么处理
- 字体怎么分层
- 截图怎么展示
- 数据怎么呈现
- 页眉页脚怎么统一
- 强调色怎么使用
- 每种页面类型怎么排版

## Prompt

请先不要生成正式 PPT 页面。

请为我的作品集建立一套统一的 Visual Code / 视觉密码。

项目名称：


项目定位：


作品集用途：


目标气质：


---

## 1. 视觉方向

请先提出 3 个可选视觉方向，每个方向包括：

- 风格名称
- 适合的项目气质
- 颜色关键词
- 材质关键词
- 版式关键词
- 适合讲什么故事
- 风险点

请你给出推荐方向，并说明为什么。

---

## 2. 视觉母版

在我确认视觉方向后，请生成一张 Styleboard / 视觉母版。

这张母版需要包含：

### A. 背景系统

请定义背景如何处理：

- 主背景色
- 是否使用渐变
- 是否使用噪点
- 是否使用液态玻璃
- 是否使用空间光
- 是否使用网格 / 轨道 / 细线
- 每页背景如何保持一致但不重复

要求：
背景要有质感，但不能抢正文。  
不要廉价渐变。  
不要赛博紫。  
不要普通白底 PPT。

### B. 字体层级

请定义：

- 中文主标题的字体气质
- 中文副标题的大小和位置
- 英文小字的使用方式
- 页码和页脚如何处理
- 每页最多允许几层文字

要求：
中文必须清晰。  
不要乱码。  
不要过多英文装饰。  
英文只做气质补充，不要抢主标题。

### C. 色彩系统

请定义：

- 主色
- 辅助色
- 强调色
- 禁用色

要求：
强调色只能少量使用。  
如果使用红色，只能作为信号点、记忆节点、关键路径提示。  
不要大面积使用红色。  
不要使用紫色、蓝紫色、荧光色。

### D. 材质系统

请定义这套作品集的材质：

- 金属
- 玻璃
- 雾面
- 半透明卡片
- 光轨
- 阴影
- 反射
- 模糊

要求：
材质要高级、克制。  
不要做成廉价 3D。  
不要把玻璃效果做得太厚重。

### E. Logo 使用规则

请定义：

- logo 出现在每页哪个位置
- 封面是否作为主视觉
- 内页是否弱化
- logo 是否可以进入系统图
- logo 是否可以作为记忆核心

要求：
logo 要统一。  
不要每页变形。  
不要每页重新生成不同形态。

### F. 小程序截图展示规则

请定义：

- 截图是否放进手机框
- 是否做成漂浮界面
- 是否做成玻璃切片
- 是否需要模糊真实个人信息
- 截图与文字的比例

要求：
截图不能像普通产品截图堆叠。  
要像作品集里的产品证据。  
如果截图文字不清晰，可以弱化截图，把重点放在结构和界面形态。

### G. 数据与指标展示规则

请定义：

- 数据如何呈现
- 指标如何呈现
- 是否使用小型信号条
- 是否使用 mini dashboard
- 如何避免 KPI 看板感

要求：
数据只是证据，不是炫耀。  
指标页要像产品迭代页，不要像商业汇报页。

### H. 系统 / 技术链路展示规则

请定义：

- 如何展示模型、数据、上下文、反馈闭环
- 如何让技术可信但不生硬
- 如何避免程序员架构图
- 如何处理 CloudBase、云函数、数据库、多模型调用这些技术信息

要求：
做成高级系统剖面。  
技术名词可以作为小字嵌入。  
不要画复杂框图。

### I. 页面类型模板

请设计至少 5 种页面模板：

1. Cover Page / 封面型
2. Origin Page / 起点型
3. Insight Page / 洞察型
4. Core System Page / 核心系统型
5. Process Page / 流程型

每种模板请说明：
- 适合放什么内容
- 主视觉放哪里
- 标题放哪里
- 文案控制多少
- 应该避免什么

---

## 3. 视觉一致性规则

请建立整套 PPT 的一致性规则：

- 每页 logo 位置统一
- 页码位置统一
- 标题最大宽度统一
- 中英文层级统一
- 红色信号点使用统一
- 图片和截图的阴影规则统一
- 卡片圆角和透明度统一
- 页面留白比例统一

---

## 4. 生成前自检清单

在生成正式页面前，请用以下清单检查：

- 这套视觉是否适合目标岗位？
- 第一眼是否有吸引力？
- 是否像作品集，而不是模板 PPT？
- 是否有统一视觉锚点？
- 是否过度依赖装饰？
- 是否能承载产品判断？
- 是否能承载技术链路？
- 是否有中文乱码风险？
- 是否有页面风格漂移风险？
- 是否有过度概念化风险？

---

## 5. 输出格式

请输出：

1. 推荐视觉方向
2. 视觉关键词
3. 色彩系统
4. 字体层级
5. 材质系统
6. logo 使用规则
7. 截图展示规则
8. 数据展示规则
9. 技术链路展示规则
10. 5 种页面模板
11. 风格一致性检查清单

最后，请生成一张 Styleboard / 视觉母版。  
我确认后，再开始生成正式页面。
