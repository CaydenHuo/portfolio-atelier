# 07 Pressure Test Skill

## 用途

用面试官视角高压追问，提前发现作品集里的薄弱点。

## Prompt

请你扮演一名字节跳动 AI 产品经理面试官，基于我的作品集项目，对我进行 challenge。

请重点从以下角度追问：

1. 这个产品是不是只是套了一个大模型？
2. 为什么用户不用 ChatGPT / 豆包 / 通义？
3. 为什么选择小程序？
4. 为什么没有做 Agent？
5. 如何解决 AI 味重？
6. 如何评估内容质量？
7. 如何判断产品真的有价值？
8. 数据从哪里来？
9. 用户不愿意填写信息怎么办？
10. 如果规模化给很多创作者使用，会遇到什么问题？

请输出：
- 10 个高压问题
- 每个问题背后的考察点
- 一个优秀回答
- 一个容易翻车的回答
- 我应该在 PPT 哪一页补强这个问题
