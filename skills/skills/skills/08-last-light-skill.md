# 08 Last Light Skill

## 用途

最后一轮审美、逻辑、表达和面试风险校准。

## Prompt

请你作为一名资深产品经理、视觉设计师和面试官，帮我审查这套作品集 PPT。

请从以下维度打分，并给出修改建议：

1. 第一眼吸引力
2. 叙事顺序
3. 页面文字是否冗余
4. 是否有清晰产品定位
5. 是否有真实用户洞察
6. 是否体现产品判断
7. 是否体现 AI 产品理解
8. 是否体现数据指标意识
9. 是否体现迭代能力
10. 是否适合线下面试展示

请特别检查：

- 是否太像概念海报
- 是否太像功能说明书
- 是否过度依赖视觉
- 是否缺少技术可信度
- 是否有面试官会追问但 PPT 没回答的问题
- 是否有页面可以删除或合并
- 是否有标题太长、太白话、太空

请输出：
- 总体评价
- 最需要修改的 5 个问题
- 最值得保留的 5 个亮点
- 每页具体修改建议
- 面试讲述时应该重点讲哪几页
